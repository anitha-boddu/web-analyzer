📘 Smart Webpage Analyzer – User Guide

📌 What is Smart Webpage Analyzer?

Smart Webpage Analyzer is an easy-to-use tool that lets you analyze any website by simply entering its URL. It includes a chat assistant, modern interface, and supports both light and dark themes.

🌟 What You Can Do

  • Submit a website URL to get insights and analysis
  • Chat with our assistant to learn about the webpage structure
  • Toggle between Light 🌞 and Dark 🌙 mode
  • Navigate across different sections easily

🖱️ How to Use

  1. Go to the Home page
  2. Paste any website URL into the input field
  3. Click the submit button
  4. Interact with the assistant for detailed analysis
  5. Toggle the theme using the icon in the top-right corner

⚠️ Things to Know

  • Currently supports basic analysis only
  • Doesn’t store your data or chat history
